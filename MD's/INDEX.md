## 🚀 Quick Commands

### Install (First Time)
```bash
# Windows
install.bat

# macOS/Linux
bash install.sh
```

### Run Server
```bash
# Windows
start_server.bat

# macOS/Linux
bash start_server.sh
```

### Access System
```
Local: http://localhost:3000
Network: http://[YOUR-IP]:3000
```

### Find Your IP
```
Windows: ipconfig
Mac/Linux: ifconfig | grep inet
```

## 🎓 Key Concepts

### LocalizedSystem
All data stays on one local server. No cloud, no internet needed.

### SQLite Database
Local database file that stores all votes permanently.

### Network Access
Any computer on same WiFi/network can vote.

### Voter Tokens
Each voter gets unique token (can't vote twice).

### Real-Time Results
Results update automatically as votes come in.
