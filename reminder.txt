Running it on voting day

Run gunicorn -w 4 -b 0.0.0.0:3000 app_pg:app instead of python app_pg.py. Note that your earlier setup was meant to work offline on a school network, and Neon needs internet on the server machine. If the school Wi-Fi is unreliable, keep a local Postgres (the Docker file) as a fallback, since only DATABASE_URL changes.
